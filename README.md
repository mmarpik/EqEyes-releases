# EqEyes

Installers and updates for EqEyes, a companion to EQSidekick for EverQuest. EqEyes reads what the game shows on
your screen (health, targets, the group, spell gems) and writes it to a text file beside the game log, so triggers
can act on it. It only looks at the game window: it does not read the game's memory, change the game or draw on it.

Download **EqEyes-win-Setup.exe** from the latest release. Installed copies update themselves from here.

More: [mazilla.se/eqeyes](https://mazilla.se/eqeyes)

EqEyes is an independent fan-made tool, not affiliated with or endorsed by Daybreak Game Company.
